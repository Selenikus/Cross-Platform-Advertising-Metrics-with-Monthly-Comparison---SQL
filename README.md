# Cross-Platform Advertising Metrics with Monthly Comparison

#### Overview
This project builds upon a previous task to merge and aggregate advertising data from Google Ads and Facebook Ads. It calculates performance metrics such as total cost, impressions, clicks, conversion value, CTR, CPC, CPM, and ROMI. The goal of this task is to provide a monthly comparison of these metrics, showing the percentage change in CPM, CTR, and ROMI from the previous month.

#### Data Sources
The SQL query utilizes data from the following tables:

* facebook_ads_basic_daily
* facebook_adset
* facebook_campaign
* google_ads_basic_daily
